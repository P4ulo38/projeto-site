# Portal de Apoio e Recursos TEA

Fala, pessoal! Este projeto foi desenvolvido por mim (**Paulo Augusto dos Reis**) junto com o meus colegas, como parte da nossa entrega para a disciplina de **Desenvolvimento Front-End para Web** na **Faculdade Módulo (Cruzeiro do Sul)**, sob a orientação do professor **Eduardo Giovannetti Motta**.

## 💡 A ideia do projeto
A gente quis criar algo que fosse além de um simples exercício de faculdade. O **Portal de Apoio e Recursos TEA** nasceu com uma pegada social e institucional, focando em trazer informações claras, diretas e acessíveis sobre direitos, serviços e recursos visuais para famílias e pessoas que convivem com o Autismo. 

A ideia principal foi unir um design humanizado e acolhedor com técnicas avançadas de programação front-end.

## 🛠️ O que a gente usou no código?
Para tirar este projeto do papel, focamos em boas práticas de engenharia web sem utilizar frameworks pesados, valorizando a essência do desenvolvimento:

* **HTML5 Semântico:** Estruturamos o site usando as tags corretas (`<header>`, `<main>`, `<article>`, `<footer>`) para garantir acessibilidade e boa indexação.
* **CSS3 Avançado:**
  * **Grid e Flexbox:** Para deixar o layout totalmente responsivo, se adaptando bem tanto em telas de notebook quanto no celular.
  * **Pseudo-elementos (`::before` e `::after`):** Esse foi um dos grandes diferenciais! A gente modelou o formato clássico de encaixe de peças de quebra-cabeça diretamente via código CSS nos cartões principais.
  * **SVGs e Animações (`@keyframes`):** Usamos gráficos vetoriais no fundo decorativo e criamos um efeito de gradiente dinâmico e fluido no título principal.
* **Controle de Versão e Deploy:** Todo o projeto foi versionado usando o **Git** integrado direto no VS Code, enviado para um repositório público no **GitHub**, e colocado no ar de forma automatizada com o **GitHub Pages**.

## 🧩 O grande diferencial visual
O grande charme do site é a identidade visual temática de quebra-cabeça. A gente trabalhou bastante nos detalhes visuais:
* Elementos flutuantes de fundo com cores vivas e posicionamento absoluto.
* Cartões estruturados em formato de peças que parecem se encaixar, simulando uma transparência suave no fundo (`opacity`) combinada com botões de alta legibilidade para garantir um contraste perfeito.
